
# Smart Study Planner

A Flask-based study planner for AP SSC Class 10 students.

## Features

- Student registration and login
- Student dashboard
- Add and manage subjects
- Add chapters and topics
- Set topic difficulty
- Track topic completion status
- Generate a study timetable
- Revision and practice-test sessions

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Installation

1. Install Python and Git.
2. Clone this repository.
3. Create a virtual environment.
4. Install dependencies using:

   pip install -r requirements.txt

5. Run the application using:

   python app.py

6. Open http://127.0.0.1:5000/ in your browser.

## Database

The application initializes its database tables automatically.
